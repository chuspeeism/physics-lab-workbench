# 物理实验工作台 · 豆包技能

人教版初中物理 21 个学生必做实验（22 个实验页）的离线 3D 互动教学网站，打包成豆包技能。

- **打开就能上课**：每个实验都能拖动 3D 器材、自动读数、记录数据，配 6 道「边做边问」和一份教学设计（钩子 · 梯子 · 坑）；另有一个拓展页「光的折射」；首页有实验库、教学设计、错题集、使用说明。
- **老师可以按自己的教法改**：在豆包里直接说要改什么——改题目和答案、改实验数值、换器材外观、加生活情境、把自己的错题写进错题集、把网页里改好的内容写进网站文件、照同样的风格做一个新实验……豆包会按技能里的说明改好，交回完整的网站文件。

## 怎么用

1. 在豆包里发送「从 Github 上安装 chuspeeism/physics-lab-workbench 这个 Skill」，等它装好；装好后新开一个任务。
2. 对豆包说「打开物理实验工作台」，右侧就会打开整个网站。
3. 想改哪里，直接告诉豆包，例如：
   - 「把凸透镜的焦距改成 15 cm。」
   - 「给浮力实验加一个 3D 的轮船情境。」
   - 「这是我整理的错题，帮我写进错题集。」

也可以不用豆包：下载 `assets/物理实验工作台.html`，双击用浏览器打开（推荐新版 Chrome 或 Edge），不需要联网。

## 仓库里有什么

|---|---|
| `SKILL.md` | 技能说明（给豆包看）：怎么打开、怎么改、四条底线、改完自检 |
| `references/site-map.md` | 网站地图：每样内容在哪个文件、哪一段 |
| `references/params.md` | 每个实验（含拓展页「光的折射」）的物理数值写在哪几处、改了影响哪些题 |
| `references/textbook.md` | 22 个实验的课本出处和结论 |
| `references/textbook-index.md` | 三册课本里所有实验、演示、想想做做的要点（做新实验、加情境前查） |
| `references/scenes.md` | 怎么给实验加生活情境（3D 场景） |
| `references/parts.md` | 零件库：剖开的水、烧杯、人、鱼、船、桌子、力的箭头、光线……搭生活情境用 |
| `references/physics.md` | 物理计算：浮沉、压强、杠杆、光（折射角入射角按课本叫）、凸透镜成像、电路、热……情境里的数都从这里算 |
| `references/scene-template.js` | 新情境的填空模板（开头是要先给老师看的情境方案） |
| `references/examples/scene-egg.js` | 完整示范：盐水浮鸡蛋 |
| `scripts/add_scene.py` | 把一个生活情境接进网站（单文件版 + 文件夹版），会备份、会核对；也能列出、拿掉情境 |
| `references/new-experiment.md` | 怎么照同样的风格做一个新实验 |
| `assets/物理实验工作台.html` | 整站单文件（约 7 MB） |
| `source/网站/` | 网站文件夹版（内容和单文件版一样，拆成了很多文件） |
| `THIRD_PARTY_NOTICES.md` | 第三方组件和图片的许可说明 |
| `LICENSE` | 开源协议（AGPL-3.0） |
