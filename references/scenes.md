# 给实验加生活情境（3D 场景）

实验页左上角有一排切换：「实验｜潜水艇｜……」。点场景名，整个舞台换成这个场景的 3D 画面，右栏换成场景自己的操作；点「实验」回来。题目、答案、记录都不受影响。

## 做的顺序（每次都按这五步）

1. **先交「情境方案」，不写代码。** 照 `references/scene-template.js` 开头那段，写清：学生要看到的现象、物体清单（每样用哪个零件）、能动手的量和范围、公式和数值、默认从哪边看、简化了什么、课本依据。发给老师，老师说可以再做（老师说了“直接做”就不用等）。
2. **复制模板，按方案填空。** 新文件从 `references/scene-template.js` 复制，按里面 1～7 段填。**物理数值、状态、名称一律用 `LabPhysics` 算**（`references/physics.md`：浮沉算到最后停在哪、折射角入射角按课本叫、凸透镜成像、欧姆定律……），不自己推公式。搭场景**先用零件库**（`references/parts.md`：剖开的水、烧杯、人、鱼、船、桌子、力的箭头、光线……），零件没有的再用 `P.lathe / P.roundBox / P.extrude / P.tube` 自己造型。完整的示范：`references/examples/scene-egg.js`（盐水浮鸡蛋）。
3. **接进网站。** 用 `python scripts/add_scene.py 情境文件.js` 接进去（见下面「交付」；试做时可以加 `--out 试做.html` 另存，不动原文件）。改了情境文件就再运行一次，它会更新。
4. **点「检查画面」，改到没有「出错」「要改」。** 打开接好的单文件版，进这个实验、切到这个情境，舞台右下角有「检查画面」按钮：它会列出标签太多、标签压住要看的东西、主体太小、出画、有水没剖开、能拖却没提示、右栏是空的、程序报错，以及物理问题（停着不动的物体受力不平衡、力的箭头太短、术语和课本不一致）等，底下有一段话可以直接照着改。自己打不开页面时，请老师点一下「检查画面」→「复制给 AI」，把那段话发回来。
5. **看截图自查。** 自己截一张默认视角的图（或请老师截图发来），逐条看：
   - 一眼能看出是什么东西吗？像实物吗（不是方块、圆柱随便拼的）？
   - 要观察的现象（像、液面、吃水线、指针、光路）在画面中间、够大、没被挡住吗？
   - 水、容器是剖开或透明的，看得见里面吗？
   - 力的箭头长短和大小对得上吗（漂浮、悬浮时两个箭头一样长）？停着不动的东西，画在它身上的力平衡吗（少画了支持力没有）？
   - 状态写对了吗（上浮、下沉是过程，停下来是漂浮、悬浮、沉底）？角的名字对吗（光从哪种介质射入哪种）？
   - 按一下右栏的每个按钮、拖一下滑杆：现象和读数跟着变吗？到了极端情况（沉底、满载、看不清）有说明吗？
   - 文字是大白话吗？和课本说法一致吗？

## 交付（每次都这样交）

1. **一次只交一个情境。** 情境 id 不能和别的情境重名；网站自带的 `camera`、`sub`、`generator`、`fish`、`chopstick` 不能用。
2. **用脚本接进网站**：`python scripts/add_scene.py scene-xxx.js`。它会把情境一起接进单文件版和文件夹版，备份原文件，并核对接好了没有。**不要自己写脚本去改 RES / PAGES**。只有不能运行 Python 时，才按下面「怎么加一个新场景」手动改。
   - **老师给了自己的文件**（上次交回的单文件版）：在老师的文件上接，加 `--single 老师的文件.html`（这时只改老师这个文件）；先运行 `python scripts/add_scene.py --list --single 老师的文件.html` 看看里面已经有哪些情境；
   - 要拿掉一个：`--remove 情境id`（老师的文件同样加 `--single`）；
   - 试做时另存一份、不动原文件：加 `--out 试做.html`。
3. **交回整站单文件**：老师给的是什么文件，就交回同名的文件；老师没给文件，就交回 `物理实验工作台.html`。老师说要“一个单独的网页”时，才按下面的“单独一个网页”做。
4. **回答里写清楚**：情境名、挂在哪个实验、改了哪些文件（新增 `scene-xxx.js`、改了哪一页）、「检查画面」的结果；做不到或简化了的地方直接说。
5. 交回的文件里不带测试用的东西、别的情境的半成品，也不带自己写的临时脚本。

**交付的两种方式**（老师没说就用第一种）：
- **接进实验页**：用 `scripts/add_scene.py` 接进网站（不能运行 Python 时按下面「怎么加一个新场景」手动接），交回完整文件。
- **单独一个网页**：老师要“一个能直接打开的网页”时，以 `source/网站/` 里这个实验的页面为底，把它引用的样式、脚本按原来的顺序全部内联进去（每段前写一行 `/* 离线内联：assets/… */`），新情境脚本放在 `physics.js` 和已有情境脚本后面、`expNN.js` 前面；交回的网页双击就能打开、左上角能切换「实验｜情境」。

## 已有的场景（照着它们的写法做）

在 `assets/lab/` 里，文件名 `scene-xxx.js`，例如潜水艇 `scene-sub.js`（13 浮力）、手摇发电机 `scene-generator.js`（22 电磁感应）、照相机 `scene-camera.js`（07 凸透镜）、叉鱼和筷子 `scene-fish.js`、`scene-chopstick.js`（拓展实验「光的折射」页）。**新做之前先打开一个已有的场景文件，照它的结构写。**

另外，13 浮力、15 电流表、07 凸透镜还有一种 2D 的「情境小卡片」（舞台右下角一张小图，如浮力的“轮船”“热气球”、电流表的“手电筒”“节日小彩灯”、凸透镜的“投影仪”“放大镜”），在「老师工具 → 定制 → 这个实验」里打开，和这里说的 3D 场景是两回事。老师要“加一个轮船情境”时，先告诉他浮力实验已有轮船小卡片；他要的是能操作的 3D 场景，再按下面做。

## 怎么加一个新场景

1. 新建情境文件 `scene-<英文名>.js`（放在哪都行，用脚本接时它会复制到网站里；手动接时文件夹版放 `source/网站/assets/lab/`），从 `references/scene-template.js` 复制后填空。最简单的样子是：

```js
LabScene.register('ship', {
  no: '13',          // 挂在哪个实验上（实验编号）
  name: '轮船',      // 切换按钮上的名字
  build: function (ctx) {
    var T = ctx.T, P = LabParts, V = P.V;   // THREE、零件库
    // 用 ctx.scene 加模型；ctx.orb / ctx.target / ctx.view() 设视角；ctx.panel(html) 写右栏；ctx.tag(id, html, 位置, { side, gap, small }) 加 3D 标签（怎么放见下面「标签怎么放」）；ctx.note(文字) 舞台左下角一行操作提示
    // ctx.drag = { start(ev){ … return true 表示接管拖动 }, move(ev){}, end(){} }；ctx.pick(ev, 物体数组) 点选
    return {
      frame: function (dt) { /* 每帧都会调用：更新模型、重新调用 ctx.tag 让标签跟着视角走；有动画就 return true */ },
      pause: function () {},   // 可选：切回「实验」时调用
      resume: function () {}   // 可选：切到这个场景时调用
    };
  }
});
```

2. 让页面加载它（**用 `scripts/add_scene.py` 就自动做好了**；下面是不能运行 Python 时的手动做法）：
   - 网站文件夹版：在 `source/网站/` 里对应实验页 HTML 中，页面依次加载 `scenes.js → parts.js → physics.js → 情境脚本 → expNN.js`；在 `physics.js` 那一行（有情境脚本就在最后一个情境脚本）后面加 `<script src="assets/lab/scene-ship.js"></script>`（`?v=…` 是原来就有的版本号，照抄或不写都行）。07 凸透镜页是自己调用 `LabScene.mount(` 的，新脚本要加在 `scene-camera.js` 那一行后面、`LabScene.mount(` 那一行前面。
   - 单文件版：在 `RES` 里加 `"assets/lab/scene-ship.js": "…脚本内容（JSON 转义）…"`，再在 `PAGES` 里这一页的 HTML 字符串中、`<!--@js:assets/lab/physics.js-->`（有情境脚本就在最后一个情境脚本）后面加 `<!--@js:assets/lab/scene-ship.js-->`。脚本里的 `"`、换行、`\` 要转义，`</` 写成 `<\/`（见 `site-map.md` 第 1 节）。
3. 框架会按 `no` 自动把切换按钮挂到这个实验上，不用改其他文件。同一个实验挂几个场景，切换按钮就按脚本加载的先后排。

`ctx` 的完整说明写在 `assets/lab/scenes.js` 开头的注释里；右栏可用的样式：`.ls-title`（`<small>生活情境</small><b>名字</b><p>一句话</p>`）、`.ls-blk` 块、`.ls-h` 块标题、`.ls-row`（`.nm` 名称 + `.vl` 数值）、`.ls-btns` 按钮组（`button.on` 选中、`button.main` 主按钮）、`.ls-big` 大号读数、`.ls-note` 结论、`.ls-tip` 小字、`input.rng` 滑杆。

## 标签怎么放（不要挡住要观察的东西）

学生要看的是现象本身：虚像在哪、光怎么走、液面到哪、指针指几。标签一压上去，现象就看不见了。

**规则**

1. **画面里常驻的标签不超过 4 个**，只标学生要认的东西（真实的鱼、看到的鱼、水面……）。其余的说明写在右栏。
2. **标签放在物体旁边，用细引线指回去，不压在物体上。** 写法：`ctx.tag(id, html, 物体中心, { side: 'below', gap: 40, small: true })`（不写第 4 个参数时，框架按 `{ side: 'above', gap: 16, small: true }` 放，也会自动避让）
   - `side`：标签放在点的哪一边，可选 `'above'`、`'below'`、`'left'`、`'right'`；
   - `gap`：离开这个点多少像素，一般 30–70；`gap` 大于 4 时框架自动画引线；
   - `small: true`：小号标签，场景里一般都用小号。
   - 位置直接给物体中心，**不要自己在 3D 坐标上加偏移**（加 2 个单位在屏幕上只有二三十像素，标签照样压在物体上）。
3. **要观察的地方用 `ctx.keepClear` 登记**，带参数的标签会自动绕开它们，彼此也会自动错开：
   `ctx.keepClear('image', 像的位置, 70)`，最后一个数是半径（像素），大约是这个物体在画面上的半宽。
   要登记的有：像（虚像、实像）、光路的折射点 / 反射点、瞄准圈、指针、液面、要比较的两个物体。
4. **两个要比较的东西，标签分开放**：上下排的（真实的鱼在下、看到的鱼在上）一个放下面、一个放旁边，别让一个的引线穿过另一个。
5. **操作提示（“拖动瞄准”“拖这里转动”）不做成画面里的标签**：用 `ctx.note('拖动水里的圆圈瞄准，再点右边的「叉下去」')` 写在舞台左下角，或写在右栏。不需要时 `ctx.note('')`。要拖的东西上用 `ctx.spot('knob', 旋钮位置)` 画一个一闪一闪的小圆点，提示文字里说“拖闪着的旋钮”；学生拖过一次后传 `null` 收起。
6. **标签要每帧更新**：`ctx.tag` 只在调用的那一刻按当前视角算一次屏幕位置，所以要在 `frame` 里每帧都调用一遍（已有场景都是这样写的），否则学生一转视角，标签就和物体分开了。
7. **标签只在有用时出现**：要隐藏时，位置传 `null`（`ctx.tag('point', '折射点', 显示光路 ? P : null, {…})`），不要传空文字再改 `style.display`。
8. 做完把默认视角截一张图看一眼：标签有没有压住鱼、像、光线、指针？压住了就换 `side` 或加大 `gap`。

**例子：叉鱼**

```js
// 不好：标签中心就在物体上方一点点，压住了鱼、像和瞄准圈；“拖动瞄准”也做成了标签
ctx.tag('real',  '真实的鱼',         F.clone().add(v3(0, -2.1, 0)));
ctx.tag('image', '看到的鱼（虚像）', A.clone().add(v3(0, 2.1, 0)));
ctx.tag('aim',   '拖动瞄准',         aim.clone().add(v3(0, -2.1, 0)));

// 好：登记不能挡的地方；标签放到旁边、小号、带引线；操作提示进左下角
ctx.keepClear('fish', F, 70); ctx.keepClear('image', A, 70); ctx.keepClear('aim', aim, 46);
ctx.keepClear('P', 显示光路 ? P : null, 26);
ctx.tag('real',  '真实的鱼',         F, { side: 'below', gap: 44, small: true });
ctx.tag('image', '看到的鱼（虚像）', A, { side: 'left',  gap: 70, small: true });
ctx.tag('surface', '水面', 水面上一点, { side: 'above', gap: 6, small: true });
ctx.tag('point', '折射点', 显示光路 ? P : null, { side: 'above', gap: 34, small: true });
ctx.spot('aim', 准备中 ? aim : null);
ctx.note(准备中 ? '拖动水里闪着的圆圈瞄准，再点右边的「叉下去」' : '');
```

## 做场景的要求

1. **物理对，按课本。** 数值、状态、名称都用 `LabPhysics` 算（`references/physics.md`），右栏照它返回的叫法写；物体要算到最后停下来的状态（上浮的最后漂浮，F浮 = G）。数值、现象、结论都要对，宁可简化也不能错；右栏写清简化了什么（如“示意图，大小不按比例”）。写清课本依据，按课本的观察角度做：先在 `references/textbook-index.md` 里查课本有没有提到这个例子、在哪一节、从什么角度讲；课本没提到的，告诉老师这是课本外的例子。
2. **能动手。** 至少有一个能操作的量（注水/排水、加货、摇快摇慢、改角度……），操作后现象和读数跟着变；可调范围覆盖课本会讨论的情况。
3. **建模精细。** 先用零件库（`references/parts.md`；画面背后空荡荡就加 `P.backdrop` 远景，只需要露出手就用 `P.hand`），零件没有的再自己造型：回转体用 `P.lathe`（瓶子、鱼身、镜头），带圆角的用 `P.roundBox`，平面轮廓用 `P.extrude`，管线用 `P.tube`；比例对、有细节，别用方块、圆柱随便拼。有水就剖开（`P.water`）或用透明容器，让学生看得见水下。
4. **构图。** 默认视角一眼看清重点；能转视角，但限制在好看的范围内。用 `P.frame(ctx, [主体…], { az, el })` 自动取景，它会顺手把转动范围、阴影都调好。
5. **大白话。** 按钮写“注水”“摇快一点”，不用“参数、模式、渲染”这类词；结论一句话，和课本说法一致。
6. **离线。** 不加载外部文件或库，只用页面里已有的 THREE。
7. **标签不挡现象。** 按上面「标签怎么放」做。
8. **三种样子都好看。** 老师可选坐标纸 / 沉浸舞台 / 手绘本；沉浸舞台时右边 496px 被浮动面板盖住、上面 92px 是顶栏，框架会自动让开，场景里的 2D 小窗放左边。
9. **只加自己的文件。** 不改 `scenes.js`、`parts.js`、`lab.js`、`lab.css` 和其他实验文件。零件不合适就在自己的场景文件里另做，不去改零件库。
10. **检查过再交。** 「检查画面」没有「出错」「要改」，截图自查过。老师验收满意后，在 `register` 里加一行 `done: true`，「检查画面」按钮就不再显示。
