# 实验参数地图：老师要改某个物理数值时，去哪里改、还要跟着改什么

老师说“把凸透镜焦距改成 15 cm”“电池改成三节”“金属块换成 5 N”时，先在本文件找到对应实验和那一行，再**按表把所有相关位置一起改**：代码里的数值、题目答案里的数字、提示文字、注释。只改一个数字、不改答案，页面会和答案对不上。

## 先看这几条（所有实验通用）

**1. 文件在哪**
- 网站文件夹版：实验程序在 `网站/assets/lab/expNN.js`（NN 是两位实验号，15～20 还会加载共用的 `assets/lab/circuit.js`）。07 没有 exp07.js，程序写在 `网站/07-探究凸透镜成像的规律.html` 里。题目、答案、实验说明在 `网站/assets/data.js`。首页「错题集」的数据在 `网站/assets/mistakes.js`。
- 单文件版 `物理实验工作台.html`：同样这些文件被整段装进字符串里。
  - 脚本和数据在 `var RES = {"assets/lab/exp13.js": "……", "assets/data.js": "……", "assets/mistakes.js": "……", …}`。
  - 各个网页（包括 07 整页）在 `var PAGES = {"07-探究凸透镜成像的规律.html": "……", …}`。
  - 在单文件里改：搜索和文件夹版**同样的变量名或文字**，就在那个字符串里改。字符串是 JSON 写法，原来的写法要保持：双引号写成 `\"`，换行写成 `\n`，反斜杠写成 `\\`，`</` 写成 `<\/`（07 页里的 `</i>` 在单文件里是 `<\/i>`）。单引号和中文不转义，照原样。新加的文字里如果有双引号或换行，也要这样写。
  - 单文件里 data.js 也是转义过的：`"no": "13"` 要搜 `\"no\": \"13\"`；代码里带双引号的片段（如 `id="s-i" min="0" max="85"`）要搜 `id=\"s-i\" min=\"0\" max=\"85\"`。不带双引号的片段（大多数变量名、`var F = 10,` 这类）照原样搜。图片在 `var IMG`（base64），改数值不用动。
  - 老师给的是哪个文件就改哪个文件。两种版本都要改时，两个地方按同样的内容改。
- 本文件表格里代码片段中的 `\|` 是表格写法需要的转义，搜索时当作 `|`（例如 `\|\|` 就是 `||`）。

**2. 题目和答案只存一份，两个页面都显示**
- data.js 里 `window.LAB.exps` 每个实验一项，用 `"no": "13"` 找到它。往下依次是：
  - `device`：装置说明
  - `reads`：读什么
  - `conclusion`：结论
  - `qs`：六道题。每道有 `q` 题目、`start` 开始时实验台摆成什么样、`a` 答案。
  - `guide`：和 qs 一一对应，每道有 `task` 做什么、`keep` 不变的条件、`watch` 观察什么。
  - `table` 和 `table2`：记录表的表头
  - `cards`：引入卡、阶梯卡、易错卡
  - `teaching`：教学设计，有的实验是 null
- 实验页和教学设计页读的都是这一份，改一次两边都更新。本文件里写的 `qs[1].a` 从 0 开始数，就是第 2 题的答案。
- 拓展页（F1 光的折射）不在 `exps` 里，在 `window.LAB.extras` 里，同样用 `"no": "F1"` 找；它只有 5 道题（qs[0]～qs[4]），没有 teaching。
- **07 例外**：实验页用的是页面里自己的 `var QS = [`（答案字段叫 `ans`），教学设计页用的是 data.js 的 07 条目。所以两份都要改，而且要改成一样。
- 老师在页面上点过「改题目」的话，改过的题存在浏览器里（`physlab.qs.NN`），会盖住 data.js。改完 data.js 页面上的题目没变时，请老师在「改题目」里点「全部改回原样」（要连点两次，第一次按钮会变成「再点一次，全部改回」；也可以只点某题的「↺ 这道题改回原样」），或者换一个浏览器看。教学设计页「改教案」改过的内容存在 `physlab.teach.NN`，同样会盖住 data.js 的 `cards` 等，在教学设计页点「全部改回原样」恢复。另外看一眼 `assets/my-changes.js`：`window.PHYSLAB_BUILTIN = null;` 不是 null 时，里面带的 `physlab.qs.NN`、`physlab.teach.NN` 也会盖住 data.js，要一起改。
- 错题集 `assets/mistakes.js` 的 `items` 里有些条目写了本实验的读数（每节末尾列出）。参数改了，这些数字也要跟着改。只改数字，别的不动。（mistakes.js 开头写的“只改 mine，不要动 items”是说老师加错题时只往 mine 里加；实验数值改了，items 里对应的读数仍要跟着改。）

**3. 改的步骤**
1. 在本文件找到要改的物理量，按“代码里在哪”搜索，改数值。
2. 用括号里的公式重新算出所有跟着变的读数，并按页面的分度值取整（页面怎么读数，答案就怎么写）。
3. 按“改的时候还要同步”的清单，逐条改 data.js 里的 `q`、`start`、`a`、`task`、`keep`、`watch`、`device`、`reads`、`cards`，以及 teaching、mistakes.js、代码开头的注释。
4. 检查“写死的地方”和“不要改”。有些判断门槛、坐标轴、放大窗只按现在的数值写好，换了数值要一起改，或者干脆不能改那么大。
5. 改完在 data.js 本实验条目、expNN.js（07 是 07 页）和 mistakes.js 本实验的几条里搜一遍**旧数值**（例如 `4.0 N`），确认没有漏掉的。

**4. 通用提醒**
- 只有 exp13.js、exp15.js 和 07 页开头有 `var CFG = {` 参数区，那里只管外观（光源图案、金属块形状、液体颜色、灯泡样式、导线颜色、情境小卡片），**不管物理数值**；这些在「老师工具 → 定制 → 这个实验」里也能点选。其他实验没有参数区，物理数值直接写在程序里。
- 电池“节数”和“电压”在代码里是两回事。`C.battery(S, { cells: N` 只决定画几节（每节都印着 1.5V），电压要另外改：15、16、17、19、20 改该实验的 `EMF`；18 没有 `EMF`，改两句 `n.cell(…, 1.5, 0.1, …)` 里的 1.5。19、20 的电表固定接在 0～3 V、0～0.6 A；15～18 虽然能换量程，但各题开局多用小量程。所以电压加到 3 V 以上往往会超量程，各节写了限制。
- 改完的数值最好让读数正好落在刻度上（例如浮力每 cm 0.1 N、光屏位置是 0.5 cm 的整数倍），否则学生读数和答案会差一格。
