# 物理计算 LabPhysics（情境里的数都从这里算）

**生活情境里的物理数值、状态、名称，一律调用 `LabPhysics` 算，不要自己推公式。** 测试中出过的错几乎都是自己推出来的：
- 潜水艇排水后上浮，停在水面下就不动了，还写着“浮力 10 N > 重力 6 N”。实际上它应该一直浮到露出水面，最后漂浮，F浮 = G。
- 筷子插水（人看水里的东西），把水里的角叫成“折射角”。光是从水射入空气的，水里的角是**入射角**。

`LabPhysics` 按课本知识点分组，返回的对象里直接带着课本的叫法（`state: '漂浮'`、`入射角`、`折射角`、`性质: '倒立、缩小的实像'`……）。右栏、标签**照返回的字写**，不要自己改叫法。

- 文件：`assets/lab/physics.js`（每个实验页都已加载，在 `parts.js` 后面）。单文件版在 `RES` 的 `"assets/lab/physics.js"`。
- 在场景里：`var Ph = LabPhysics;`
- **单位一律用国际单位**：m、kg、N、Pa、s、V、A、Ω、W、J、℃，角度用“度”。画面里的尺寸可以是厘米（零件库推荐 1 单位 = 1 cm），**算之前除以 100 换成米**。
- `Ph.g` 默认 10 N/kg（课本练习的取法），要 9.8 就设 `Ph.g = 9.8`。

## 常数

| 写法 | 内容 |
|---|---|
| `Ph.RHO.水` 等 | 密度 kg/m³：水 1.0×10³、海水 1.03×10³、酒精 / 煤油 0.8×10³、水银 13.6×10³、冰 0.9×10³、铁 7.9×10³、铜 8.9×10³、铝 2.7×10³…… |
| `Ph.C.水` 等 | 比热容 J/(kg·℃)：水 4.2×10³、冰 2.1×10³、沙石 0.92×10³、铝 0.88×10³、铜 0.39×10³…… |
| `Ph.Q.酒精` 等 | 热值 J/kg：干木柴 1.2×10⁷、酒精 3.0×10⁷、汽油 4.6×10⁷…… |
| `Ph.N.水` | 折射率（课本不讲数值）：水 1.33、玻璃 1.5 |
| `Ph.P0` | 标准大气压 1.013×10⁵ Pa（约 760 mm 水银柱） |
| `Ph.V_SOUND`、`Ph.V_LIGHT` | 声速 340 m/s、光速 3×10⁸ m/s |
| `Ph.MELT`、`Ph.BOIL` | 熔点、沸点 ℃（水 0 / 100、海波 48、酒精沸点 78、水银 −39 / 357） |

## 浮力和浮沉（最容易错）

**`Ph.floatSink({ m 或 G, V, rho, shape })`**：物体放进液体，**最后停在哪**。
- 返回 `state`：`'漂浮' | '悬浮' | '沉底'`，是最后停下来的状态。
- `process`：`'上浮' | '下沉' | ''`，是浸没后松手那一刻往哪走。**上浮、下沉是过程，不是停下来的状态。**
- `Fb` 浮力、`G` 重力、`N` 容器底的支持力（沉底时 N = G − F浮）。
- `Vsub` 排开的体积、`frac` 浸入的比例、`depth` 浸入的深度（要给 `shape`）。
- `why`：一句课本说法，可直接写进右栏。
- `shape`（算浸入多深用）：
  - `{ type: 'box', h, w, d }`：长方体、竖直圆柱（给底面积就写 `A`）；
  - `{ type: 'sphere', r }`：球；
  - `{ type: 'spheroid', a, c }`：鸡蛋，a 是横半径，c 是竖半轴；
  - `{ type: 'hcyl', r, L }`：横躺的圆柱，潜水艇、木头；
  - `{ type: 'fn', vol: function (浸入深度) { … }, h }`：其他形状。

**`Ph.buoyancyAt(ρ液, shape, 浸入深度)`**：物体还在上浮、下沉的路上时，某个位置的浮力。

**`Ph.buoyancy(ρ液, V排)`**：F浮 = ρ液 g V排。

**`Ph.submergedDepth(V排, shape)`**：排开这么多体积时，浸入有多深。

写法（物体慢慢走到最后停的位置）：
```js
var fin = Ph.floatSink({ G: G, V: V, rho: Ph.RHO.水, shape: { type: 'hcyl', r: 0.05, L: 0.13 } });
var restY = fin.state === '沉底' ? 底部高度 : fin.state === '漂浮' ? 水面高度 - fin.depth * 100 : 当前高度;   // 画面单位是厘米
y = Ph.approach(y, restY, dt, 1.5);          // 每帧往目标靠近
// 还在走的时候：状态写 fin.process（上浮 / 下沉）；到了：写 fin.state（漂浮 / 悬浮 / 沉底），浮力用 fin.Fb
```

## 压强
- `Ph.pressure({ F, S, p })`：p = F / S，已知两个求第三个。
- `Ph.liquidPressure(ρ, h)`：p = ρ g h，h 是到液面的竖直深度。
- 大气压：`Ph.P0`，约 760 mm 水银柱；粗算取 1×10⁵ Pa。

## 杠杆、滑轮、功、运动
- `Ph.lever({ F1, L1, F2, L2 })`：缺哪个求哪个；`type` 是 `'省力杠杆' | '费力杠杆' | '等臂杠杆'`。
- `Ph.torques([{ F, d }, …])`：一根杠杆上的几个力。d 带正负：支点左边为负、右边为正；F 向下为正。返回 `tilt`：`'平衡' | '左端下沉' | '右端下沉'`（杆秤、跷跷板）。
- `Ph.pulley({ G, n, Gm, h })`：滑轮组。F = (G + G动) / n，绳子自由端移动 s = n h，机械效率 `eta`。
- `Ph.work(F, s)`、`Ph.power(W, t)`、`Ph.speed({ s, t, v })`。
- `Ph.balance([力向量…])`：几个力加起来是不是零。

## 光（名字照返回的写）
- `Ph.reflect(入射角)`：反射角 = 入射角。`Ph.mirrorImage(点, 镜面上一点, 镜面法线)`：平面镜成的像（正立、等大的虚像，像距等于物距）。
- **`Ph.lookIntoWater({ eye, obj, n })`——人在空气里看水里的东西**（叉鱼、筷子、池底、硬币、游泳池变浅）。
  - `eye`、`obj` 是同一个竖直剖面里的点 `{ x, y }`，水面 `y = 0`，水下 y 为负。
  - 返回：`P` 水面上的折射点、`入射角`（在水里）、`折射角`（在空气里）、`image` 看到的像（虚像）的位置、`apparentDepth` 看起来的深度、`说法`。
  - 光路：物体 → P → 眼睛，画实线；P → 像，画虚线（反向延长线）。
- `Ph.refract({ from: '空气', to: '水', angle: 入射角 })`：激光从一种介质射入另一种。返回 `入射角`、`折射角`、`偏折`（靠近 / 偏离法线）、`说法`。
- `Ph.apparentDepth(真实深度, 视线和竖直方向的夹角, n)`：看起来的深度；从正上方看，等于真实深度 / n。
- `Ph.lens({ f, u, h })`：凸透镜成像。返回 `v`（虚像为负）、`像高`、`性质`（如 `'倒立、缩小的实像'`）、`区间`（如 `'u > 2f'`）、`应用`（照相机 / 投影仪 / 放大镜）、`像在`。u = f 时 `性质: '不成像'`。

## 电
- `Ph.ohm({ U, I, R })`：缺哪个求哪个。
- `Ph.series(R 列表, U)`、`Ph.parallel(R 列表, U)`：总电阻、电流、各电阻的电压 / 电流。
- `Ph.power({ U, I, R, P })`：给两个，求其余。
- `Ph.lamp(额定电压, 额定功率, 实际电压)`：小灯泡的实际功率和 `亮度`（`'不亮' | '几乎不亮' | '很暗' | '较暗' | '正常发光' | '比正常亮（可能烧坏）'`）。
- `Ph.electricEnergy(P, t)`：W = P t，`.kWh` 是千瓦时（度）。
- `Ph.jouleHeat(I, R, t)`：Q = I²R t。
- `Ph.induction({ closed, cutting, speedRel, dirSign })`：有没有感应电流、相对大小、方向、`说法`。
- `Ph.ac(峰值, 频率, t)`：交流电在 t 时刻的值。
- `Ph.electromagnet({ I, turns, core })`：电磁铁磁性强弱。

## 热和声
- `Ph.heat({ c, m, dT, Q })`：Q = c m Δt，缺哪个求哪个。
- `Ph.fuelHeat(q, m)`：Q = q m。
- `Ph.mixTemp([{ c, m, t }, …])`：几份液体混合后的温度。
- `Ph.phase(物质, 温度, '吸热' | '放热')`：`'固态' | '液态' | '气态'`。正在加热、到了沸点：“液态（正在沸腾，继续吸热，温度不变）”；在熔点：吸热时“固液共存（正在熔化）”，放热时“固液共存（正在凝固）”，不说吸热放热时“可能是固态、液态或固液共存”（课本：晶体熔化时温度不变；沸腾时温度不变但要继续吸热）。
- `Ph.echo({ d })` / `Ph.echo({ t })`：回声，t = 2d / v。

## 工具
- `Ph.approach(当前, 目标, dt, 快慢)`：让数值平滑地走向目标（上浮、下沉、指针摆动）。
- `Ph.fmt(数, 位数)`：保留几位小数。
- `Ph.sci(数, 单位)`：写成 `1.50×10⁷ N`。

## 「检查画面」会查的物理问题

1. **静止的物体受力必须平衡。** 力的箭头（`LabParts.arrow`）要写 `on: 受力的物体`。物体停着不动、箭头加起来却不为零，就报「要改」。常见原因有两个：一是没算到最后的状态（上浮停在水下），二是少画了一个力（沉底时的支持力、杠杆支点的力）。
2. **主要的力，箭头在画面上太短。** 同一个场景所有力用同一个比例，漂浮、悬浮时两个箭头一样长。本来就很小的力（如很小的支持力）箭头短是对的，不会报。
3. **术语和课本不一致。** 例如人看水里的东西，却把水里的角叫成“折射角”；写“停表”（课本叫“秒表”）。

课本外的规律（`LabPhysics` 里没有的），在情境方案里写明“课本外”，算法写清楚，交给老师确认。
