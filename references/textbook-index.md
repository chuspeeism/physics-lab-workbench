# 课本实验索引（人教版初中物理三册）

三册课本里每一个「实验」「演示」「想想做做」：出处、器材（几件、怎么拿）、摆法、步骤先后、记录表、结论、注意点和课本提到的生活例子。共 142 条（演示 50、想想做做 42、实验 50）。

用法：

- 老师要做网站里没有的实验，或给实验加生活情境时，先在这里按实验名、章节或关键词查。查到了，就照这里的器材、摆法、步骤先后和记录表列做法给老师确认；查不到，就按你自己的了解列，并告诉老师“课本里没有这个，我是这样设计的”。
- 这里是按课本整理的要点，用我们自己的话写的，不是课本原文，也没有插图。页码、图号用来和老师对照；老师手上的课本版本不同时，以老师说的为准。
- 课本做法是默认做法，不是硬规定：老师想换器材、换做法，照老师说的做。

## 八年级上册

### 开启科学探索之旅

**演示 · 奇妙的物理世界（重新沸腾的水、转动的线圈）**（奇妙的物理世界，第 2 页，图1）
- 器材：烧瓶一个（装水，配瓶塞）、热源、冷水；线圈一个、支架一个、强磁体一块、电源
- 摆法：实验一：水烧开后离开热源，塞紧瓶塞把烧瓶倒过来；实验二：线圈搁在支架上，正下方放强磁体，线圈接电源。
- 步骤：把烧瓶里的水烧开，再把烧瓶从热源上移开，水不再翻滚 → 立刻塞好瓶塞，把烧瓶倒过来，往瓶底浇冷水，看瓶内的水有什么变化 → 把线圈架在支架上，线圈下面放一块强磁体 → 接通电源让线圈中有电流，看线圈会怎样
- 结论：课本只要求观察、感受物理的奇妙，不讲原理：浇冷水后瓶里的水会再次沸腾，通电线圈会在磁体上方转起来。
- 注意 / 常见做错：一个演示框里含两个小实验
- 课本提到的生活例子：电闪雷鸣、雨后彩虹、树叶下落而飞机能上天（引言中的问题）

**想想做做 · 用放大镜看远近物体；向下吹漏斗里的乒乓球**（奇妙的物理世界，第 3 页，图3）
- 器材：放大镜两个（两只手各握一个）；漏斗一个（倒扣）、乒乓球一个
- 摆法：两个放大镜一前一后对着前方物体，二者距离可调；漏斗口朝下，乒乓球放进漏斗里用手指托住。
- 步骤：拿一个放大镜先观察手指上的指纹，然后改看窗外景物，比较两次所见 → 两手各拿一个放大镜，透过两个镜子看前方物体，同时调节两镜之间的距离 → 把乒乓球放进倒扣的漏斗，用手指从下面托住 → 从漏斗细口用力往下吹气，同时把手指移开，看球会不会掉下来
- 结论：课本只提出问题、留待以后解释；实际现象是：两个放大镜配合调好距离能看清远处物体，用力向下吹气时乒乓球不会掉下来。
- 注意 / 常见做错：一个想想做做框里含两个小活动；结论课本没写，是补充说明，课本此处未给出

### 第一章 机械运动

**实验 · 比一比两根小棒谁长（节首问题）**（第1节 长度和时间的测量，第 11 页，图1.1-1）
- 器材：课本图中的两根小棒、刻度尺一把
- 步骤：先只凭眼睛判断图中两根小棒哪根更长 → 再用尺子实际量一量，和刚才的判断对比
- 结论：光靠感觉判断长短不一定对，想准确就要用工具测量。
- 注意 / 常见做错：课本以节首「问题」栏呈现，没有实验框

**实验 · 用刻度尺测量长度**（第1节 长度和时间的测量，第 13 页，图1.1-4） — 网站 01
- 器材：刻度尺一把；铅笔（或其他物体）、作业本、课本
- 摆法：刻度尺的零刻度线对齐物体一端，有刻度的一边贴紧被测边并与它平行。
- 步骤：先认识自己的刻度尺：零刻度线位置、能测的范围（量程）、分度值 → 练习量铅笔的长度，说说怎样用尺才对 → 放尺：零刻度线对准物体一端，刻度边紧贴被测边、保持平行不歪斜 → 读数：眼睛正对所读的刻度线 → 记录：写数值的同时写上单位 → 分别量作业本和课本的长、宽、厚，填进表格
- 为什么这样做：用任何测量工具前都得先弄清它的量程和分度值；再按测量要求选工具，比如门窗用卷尺、螺母用游标卡尺。
- 记录表：测量对象 | 长度 | 宽度 | 厚度
- 结论：用刻度尺要放得正、看得正、记得全（数值加单位），才能测准长度。
- 注意 / 常见做错：刻度尺放歪、不与被测边平行；读数时斜着看刻度线；只写数字不写单位，这样的记录没有意义；误差只能减小（多测几次取平均、换更精密的工具、改进方法），不能消除；误差和测量错误不是一回事
- 课本提到的生活例子：量门窗长宽用卷尺、精确量螺母尺寸用游标卡尺、成年人走两步约1.5 m，课桌高约0.75 m

**实验 · 用秒表测量时间**（第1节 长度和时间的测量，第 15 页，图1.1-7） — 网站 01
- 器材：秒表一块（机械或电子）
- 步骤：按一按秒表上的按钮，看指针或数字怎样变化，弄清开始、停止、归零的用法 → 用秒表测自己的脉搏跳10次要几秒 → 测正常走路时迈出一步要几秒
- 结论：会用秒表测出较短的时间间隔。
- 注意 / 常见做错：受仪器和方法限制，测量值和真实值总有差别（误差）；不守使用规则、粗心读数造成的是错误，可以避免
- 课本提到的生活例子：运动场上计时、测脉搏、走路迈步的时间

**实验 · 测量小车运动的速度**（第4节 速度的测量，第 25 页，图1.4-2） — 网站 02
- 器材：长木板一块、木块一个（垫高木板一端）、小车一辆、金属片一块、刻度尺一把、秒表一块
- 摆法：用木块把长木板一端垫起，搭成坡度很小的斜面；小车从斜面最高处出发，金属片挡在所测路段的终点处（先放底端，后移到中部）。
- 步骤：小车放斜面顶端、金属片放底端，用刻度尺量出小车要走的路程s1 → 放开小车同时开始计时，听到小车撞上金属片时停止计时，得到t1 → 用v1=s1/t1算出小车走完全程的平均速度 → 把金属片移到斜面中部，量出顶端到金属片的距离s2 → 再让小车从顶端滑下，测出走完上半段用的时间t2，算出上半段平均速度v2 → 把数据填进表格
- 为什么这样做：测平均速度需要路程和时间两个量，所以用刻度尺量路程、用秒表计时，再用v=s/t算出来。
- 记录表：路程 | 运动时间 | 平均速度
- 结论：小车沿斜面越滑越快，上半段的平均速度比全程的小；说平均速度时要讲清是哪一段路程或哪一段时间的。
- 注意 / 常见做错：斜面坡度要保持很小；讨论题：想测下半段速度时，若让小车从中部由静止开始滑，测出的结果和全程下滑时的下半段速度不相等；结论中的速度大小关系课本没写，是补充说明，课本留空让学生总结
- 课本提到的生活例子：公路区间测速：两处摄像头记下车辆经过的时刻，算出这段路的平均速度

**实验 · 用传感器测量物体运动的速度（拓展实验）**（第4节 速度的测量，第 26 页，图1.4-3）
- 器材：小车一辆（A）、斜面一个、超声波位置传感器一个（B，固定在斜面一端）、计算机一台
- 摆法：传感器装在斜面一端对着小车，并与计算机相连。
- 步骤：让小车在斜面上运动，传感器用超声波随时测出小车与它的距离 → 计算机结合时间算出小车在各位置的速度并显示在屏幕上 → 也可以把传感器摆好，人面对它前后走动，在屏幕上看自己的行走速度
- 结论：用传感器配合计算机，可以即时测出并显示物体运动速度的变化。
- 注意 / 常见做错：课本此框标为「拓展实验」，不属于实验/演示/想想做做三类，这里暂归为实验
- 课本提到的生活例子：人前后走动测步行速度

### 第二章 声现象

**想想做做 · 物体发声时有什么共同特征**（第1节 声音的产生与传播，第 32 页，图2.1-2）
- 器材：橡皮筋一根（拉紧）；自己的手
- 步骤：把橡皮筋绷紧后拨动，一边听声音一边看橡皮筋的样子 → 一边说话一边用手摸脖子前面的喉头 → 比较几种情况，找出物体发声时都有的特点
- 结论：声音是由物体振动产生的。
- 注意 / 常见做错：由多个发声实例概括出一般结论，用的是归纳推理
- 课本提到的生活例子：蝈蝈发声、说话时声带在振动、机械唱片：唱针随沟槽振动把声音重现

**演示 · 研究声音的传播**（第1节 声音的产生与传播，第 33 页，图2.1-4）
- 器材：闹钟一个（正在响铃）、玻璃罩一个（放在带抽气口的底座上）、抽气装置
- 摆法：响着的闹钟放在底座上，用玻璃罩罩住，罩内空气可从抽气口抽出或放入。
- 步骤：把正在响铃的闹钟放进玻璃罩 → 慢慢抽出罩里的空气，注意铃声怎么变 → 再让空气慢慢回到罩里，注意铃声怎么变
- 结论：抽气时铃声越来越小，放进空气后又变大：声音要靠空气等介质传播，真空不能传声。
- 注意 / 常见做错：抽气装置按课本插图推断
- 课本提到的生活例子：太空没有空气，航天员离得再近也要用无线电交谈、击鼓时鼓面带动空气振动，形成向外传的声波

**想想做做 · 桌子能不能传声**（第1节 声音的产生与传播，第 34 页，图2.1-6）
- 器材：桌子一张；同学两人
- 摆法：一名同学把耳朵贴在桌面上，另一名同学在桌子另一处刮桌面。
- 步骤：一位同学把耳朵紧贴在桌面上 → 另一位同学用指甲轻轻刮桌子，轻到旁边的同学听不见 → 贴着桌面的同学说说能不能听到
- 为什么这样做：刮得很轻、让附近的人听不到，才能说明耳朵听到的声音是经桌子传来的，而不是从空气传来的。
- 结论：固体能传声；声音的传播需要介质，气体、液体、固体都可以，真空不行。
- 课本提到的生活例子：快上钩的鱼会被岸上的说话声、脚步声吓跑、花样游泳运动员在水下能听到音乐

**想想做做 · 钢尺振动快慢与音调**（第2节 声音的特性，第 37 页，图2.2-2）
- 器材：钢尺一把、桌子一张（一只手把钢尺压在桌边，另一只手拨）
- 摆法：钢尺一端用手紧压在桌面上，另一端伸出桌边，拨动伸出的部分。
- 步骤：让钢尺伸出桌边较长，拨动它，观察振动快慢 → 一点点缩短伸出的长度，每次都拨一下，比较振动快慢和伸出长度的关系 → 伸出部分短到一定程度时能听到清楚的声音，留意音调 → 继续缩短再拨，听音调怎么变，分析音调和振动快慢的关系
- 为什么这样做：伸出长时振动慢、看得清却听不到声，伸出短时听得到声却看不清快慢，所以要把前后两段观察连起来推理得出结论。
- 结论：钢尺伸出越短振动越快，音调越高：发声体振动越快（频率越高），音调越高。
- 注意 / 常见做错：钢尺要紧压在桌面上再拨
- 课本提到的生活例子：能听到蚊子飞的嗡嗡声，却听不到蝴蝶扇翅膀

**演示 · 观察声音的波形**（第2节 声音的特性，第 38 页，图2.2-3）
- 器材：频率不同的音叉两个、橡皮锤、示波器（或计算机、手机）
- 摆法：音叉的声音信号接入示波器（或计算机、手机），在屏幕上以波形呈现。
- 步骤：敲响一个音叉，把声音信号送进示波器（或计算机、手机），观察波形 → 换一个频率不同的音叉，边听边比较两种波形
- 结论：音调高的声音波形密，频率高；音调低的波形疏，频率低。
- 注意 / 常见做错：频率单位是赫兹（Hz）；多数人能听到20~20 000 Hz，高于上限叫超声波，低于下限叫次声波
- 课本提到的生活例子：猫、狗能听到人耳听不到的高频声音

**演示 · 决定响度的因素**（第2节 声音的特性，第 40 页，图2.2-4）
- 器材：音叉一个、橡皮锤一个、乒乓球一个（用细绳吊在铁架台上）
- 摆法：乒乓球用细线挂在铁架台横杆下，音叉立在旁边，发声的音叉刚好能轻碰到球。
- 步骤：敲响音叉，让它轻轻碰一下吊着的乒乓球，看球被弹开多远 → 改变敲击力度，让音叉发出大小不同的声音，再做一次 → 比较球弹开的幅度和声音大小的关系
- 为什么这样做：音叉的振动幅度不易直接看见，借乒乓球被弹开的远近把它放大显示出来。
- 结论：敲得越重，球弹得越远，说明音叉振幅越大，响度越大；响度还跟听者离声源的远近有关。
- 注意 / 常见做错：乒乓球只需轻触正在发声的音叉
- 课本提到的生活例子：使劲击鼓比轻敲声音大、人离声源越远，听到的声音越弱

**演示 · 比较不同乐器发出声音的波形**（第2节 声音的特性，第 41 页，图2.2-5）
- 器材：计算机或手机一台（播放音叉、钢琴、长笛同一个音的录音）、三者的波形图
- 步骤：依次播放音叉、钢琴、长笛三者演奏同一音高（C调do）的片段 → 边听边对照三段波形，找出相同和不同之处
- 结论：音调相同时三者波形疏密一样（频率相同），但形状不同，说明音色不同；音色由发声体的材料和结构决定。
- 课本提到的生活例子：钢琴、长笛、编钟、鼓、二胡、贾湖骨笛等打击、弦、管乐器

**演示 · 声音能否传递能量**（第3节 声的利用，第 46 页，图2.3-6）
- 器材：扬声器一个、蜡烛一支（点燃）、音乐音源
- 摆法：扬声器正对着烛焰摆放。
- 步骤：点燃蜡烛，把扬声器对准烛焰 → 用扬声器播放音乐，观察烛焰
- 结论：烛焰随着声音颤动，可见声波可以把能量传出去。
- 课本提到的生活例子：超声波清洗机清除污垢、医生用超声波把结石击碎

**演示 · 观察噪声的波形**（第4节 噪声的危害和控制，第 49 页，图2.4-1）
- 器材：泡沫塑料块一块、玻璃一块、音叉一个、示波器或计算机
- 步骤：用泡沫塑料块刮玻璃，把发出的声音显示成波形 → 再显示音叉声音的波形，两者对比
- 结论：噪声波形杂乱没有规律，是发声体做无规则振动产生的。
- 课本提到的生活例子：深夜里有人大声唱歌，从环保角度看也是噪声

**实验 · 跨学科实践：制作隔音房间模型**（第5节 跨学科实践：制作隔音房间模型，第 53 页，图2.5-2）
- 器材：包装盒或鞋盒一个（当「房间」）、闹钟一个（当声源）、几种隔音材料、能测声音强弱的手机或计算机软件
- 摆法：闹钟放进盒子里，盒内相应位置装上隔音材料。
- 步骤：查资料比较常见材料的隔音性能，选隔音好又不太厚的材料 → 盒子未做隔音处理时，用软件测一次闹钟铃声的强弱 → 在盒内装好隔音材料，再测一次铃声强弱 → 比较前后变化，评价模型的隔音效果 → 从隔音效果、占用空间、材料是否易得安全环保等方面展示、互评并改进
- 为什么这样做：先测没做隔音时的声音作对照，再测处理后的，比较两次差别才能判断隔音效果。
- 结论：选用合适的隔音材料能阻断声音传播，盒外测到的铃声明显变弱。
- 注意 / 常见做错：课本为「跨学科实践」项目，没有实验框，暂归为实验；材料要尽量薄，给「房间」留足空间

**实验 · 用温度计测量水的温度**（第1节 温度，第 60 页，图3.1-4） — 网站 03

**实验 · 探究水在沸腾前后温度变化的特点**（第3节 汽化和液化，第 71 页，图3.3-2） — 网站 04
- 器材：烧杯一个（装水）、实验室用温度计一支、酒精灯一盏（也可用电磁炉、电热水壶等）、陶土网、铁架台、带孔的硬纸板盖一块、计时器、坐标纸
- 摆法：烧杯放在铁架台的网上，杯口盖纸板，温度计穿过纸板插进水中，下面用酒精灯加热。
- 步骤：按图装好器材，开始给水加热 → 水温快到90 °C时开始计时 → 每隔0.5 min读一次温度并记录 → 水沸腾后再继续加热4~5 min才停止记录 → 观察沸腾时气泡的变化 → 用数据画出温度—时间图像，总结规律，写探究报告与同学交流
- 为什么这样做：和熔化实验思路一样；光看表格不易看出规律，所以要把数据画成图像来分析。

- 结论：水沸腾前温度不断上升，沸腾后温度保持不变（这个温度叫沸点），但要持续加热，说明沸腾时不断吸热；沸腾时大量气泡上升、变大，到水面破裂。

**想想做做 · 酒精蒸发吸热**（第3节 汽化和液化，第 73 页）

**实验 · 探究光的反射定律**（第2节 光的反射，第 93 页，图4.2-3） — 网站 05
- 器材：平面镜一块（平放在桌上）、纸板一块（由两块纸板ENF连成，可沿ON前后折）、激光笔一支、不同颜色的笔若干、量角器一个
- 摆法：平面镜水平放在桌面上，纸板竖直立在镜面上，纸板上画的ON线与镜面垂直。
- 步骤：让一束光贴着纸板射到O点，经镜面反射后射出 → 用笔在纸板上画出入射光EO、反射光OF的路径 → 改变入射角度多做几次，每次换一种颜色的笔描线 → 取下纸板，用量角器量出ON两侧的∠i和∠r，填表 → 把纸板NOF向前或向后折，看纸板上还能不能看到反射光 → 总结光反射的规律
- 为什么这样做：要找反射光和入射光的位置关系，就要测出它们与法线的夹角，并且换不同入射角多测几次再分析。
- 记录表：次数 | ∠i | ∠r
- 结论：入射光、反射光与法线共面；两光分处法线两边；反射角与入射角相等（光的反射定律）；让光逆着反射光射入，它会沿原入射方向射出（光路可逆）。
- 注意 / 常见做错：注意避免激光射入眼睛；光要贴着纸板射入，纸板上才显示光路；纸板要垂直立在镜面上
- 课本提到的生活例子：敦煌光热电站的定日镜把阳光反射到吸热塔顶、你在镜子里看到同学的眼睛，同学也能从镜中看到你、黑板反光看不清字、玻璃幕墙造成光污染（镜面反射）

**实验 · 探究平面镜成像的特点**（第3节 平面镜成像，第 98 页，图4.3-2） — 网站 06
- 器材：玻璃板一块（竖直放置，当平面镜，用支架固定）、外形相同的蜡烛两支（一支点燃、一支不点燃）、长度不同的蜡烛若干、白纸一张、笔、刻度尺一把
- 摆法：桌上铺白纸，玻璃板竖直立在纸上；点燃的蜡烛放在玻璃板前，未点燃的蜡烛在玻璃板后移动。
- 步骤：桌面铺纸，竖立玻璃板，沿玻璃板在纸上画线代表镜面位置 → 把点燃的蜡烛放在玻璃板前 → 在玻璃板后移动未点燃的蜡烛，直到从前面看它和像完全重合，在纸上标出蜡烛和像的位置 → 量出蜡烛和像到镜面的距离并记录 → 改变点燃蜡烛的位置多做几次，留意像的大小变不变 → 换不同长度的蜡烛再做，比较像和蜡烛是否一样大
- 为什么这样做：用一支外形相同但不点燃的蜡烛去和像重合，就能找到像的位置并比较像与物的大小；课后练习还追问为何用玻璃板而不用平面镜（玻璃板透明，能同时看到板后的蜡烛）。
- 记录表：次数 | 蜡烛到平面镜的距离/cm | 蜡烛的像到平面镜的距离/cm
- 结论：平面镜成虚像，像和物一样大、到镜面距离相等，像物连线垂直于镜面，也就是像与物关于镜面对称。
- 注意 / 常见做错：玻璃板要竖直放置，否则后面的蜡烛无法与像重合；第一条为常见做错情况，课本未明说
- 课本提到的生活例子：国家大剧院在水中的倒影、照镜子、牙医口镜、潜望镜用平面镜、汽车后视镜、路口反光镜是凸面镜，太阳灶是凹面镜

- 结论：光从空气斜射入水中时方向发生偏折（折射），折射光靠近法线，折射角小于入射角，入射角变大折射角也变大；垂直射入时方向不变；折射中光路也可逆。
- 课本提到的生活例子：池水看起来比实际浅，不会游泳的人不要贸然下水、叉鱼要对准看到的鱼的下方、海市蜃楼

### 第五章 透镜及其应用

**演示 · 两种透镜对光的作用**（第1节 透镜，第 115 页，图5.1-5）
- 器材：凸透镜一块、凹透镜一块、能射出几束平行光的光源
- 摆法：几束光与透镜主光轴平行射向透镜。
- 步骤：让几束平行于主光轴的光射向凸透镜，看光穿过后往哪边偏 → 换成凹透镜，同样观察光穿过后的偏折方向
- 结论：凸透镜使光会聚（会聚透镜），凹透镜使光发散（发散透镜）；平行于主光轴的光经凸透镜会聚到焦点，焦距越小会聚作用越强。
- 课本提到的生活例子：放大镜正对太阳能在纸上聚出很亮的小光斑，久照会把纸烤焦、远视镜片是凸透镜，近视镜片是凹透镜

**想想做做 · 利用阳光测量凸透镜的焦距**（第1节 透镜，第 116 页，图5.1-7）
- 器材：焦距不同的凸透镜几块、太阳光、白纸一张（当光屏）、刻度尺一把
- 摆法：凸透镜正对太阳，白纸放在透镜另一侧。
- 步骤：让凸透镜正对太阳（阳光可看作平行光） → 在透镜另一侧前后移动白纸，直到纸上的光斑最小最亮 → 量出光斑到透镜中心的距离，就是焦距 → 换几块不同的凸透镜分别测
- 为什么这样做：太阳离得非常远，照到地面的光可当平行光，平行光经凸透镜会聚的点就是焦点。
- 结论：最小最亮光斑处就是焦点，它到透镜光心的距离即焦距。
- 注意 / 常见做错：光斑处温度很高，不要长时间照着纸

**想想做做 · 自制模型照相机**（第2节 生活中的透镜，第 119 页，图5.2-3）

- 结论：薄膜上得到窗外景物倒立、缩小的像，照相机就是这样成像的。
- 注意 / 常见做错：课后练习：想让像变大，要靠近景物并拉长透镜到薄膜的距离
- 课本提到的生活例子：胶片照相机、数码照相机用感光元件代替胶片

**演示 · 观察投影仪成像**（第2节 生活中的透镜，第 119 页，图5.2-4）

**实验 · 探究凸透镜成像的规律**（第3节 凸透镜成像的规律，第 122 页，图5.3-2） — 网站 07
- 器材：发光二极管做的发光物体一个、凸透镜一块（已知焦距f）、白色硬纸板光屏一块、带刻度的光具座一个
- 摆法：发光物体、凸透镜、光屏依次放在光具座上，三者中心调到同一高度。
- 步骤：记下凸透镜焦距f，把发光物体、透镜、光屏的中心调到同一高度 → 发光物体放在远处，移动光屏得到清晰的实像，看大小、正倒，测出物距和像距 → 把发光物体向透镜移近几厘米，重复上一步 → 继续移近，直到光屏上接不到像时，撤掉光屏，从光屏这一侧透过透镜看物体的像 → 把各次数据和观察结果填表，各组共享数据 → 以焦距f为参照分析物距和像距，总结成像规律
- 为什么这样做：让物体从远处逐渐靠近透镜，便于看出像的变化和物距的关系；凸透镜对光偏折的程度和焦距有关，所以用f作参照描述物距、像距更容易看出规律。
- 记录表：物距/cm | 像的性质：虚实 | 像的性质：大小 | 像的性质：正倒 | 像距/cm
- 结论：物距大于2f成倒立缩小实像；等于2f成倒立等大实像；在f与2f之间成倒立放大实像；小于f成正立放大虚像。
- 注意 / 常见做错：三者中心要等高，像才能落在光屏中央；成虚像时光屏接不到像，要撤去光屏从另一侧向透镜看
- 课本提到的生活例子：照相机（倒立缩小实像）、投影仪（倒立放大实像）、放大镜（正立放大虚像）

**实验 · 跨学科实践：制作望远镜**（第5节 跨学科实践：制作望远镜，第 130 页，图5.5-4）
- 器材：凸透镜两块（物镜：焦距较长、直径较大，例如焦距约20 cm、直径约5 cm；目镜：焦距较短、直径较小，例如焦距约10 cm、直径约4 cm）、粗细两段镜筒（羽毛球筒或卷起的瓦楞纸板）
- 摆法：物镜装在较粗镜筒的前端，目镜装在较细镜筒的一端，细筒插入粗筒内可前后伸缩。
- 步骤：了解原理：物镜先把远处景物成一个实像（位置靠近焦点），目镜相当于放大镜，再把它放大 → 定放大倍率（2~3倍即可），倍率等于物镜焦距除以目镜焦距 → 测出手头凸透镜的焦距和直径，选好物镜和目镜 → 按焦距、直径做两段能套接的镜筒，把镜片固定好 → 目镜筒插进物镜筒，对着远处物体，伸缩镜筒直到看清 → 展示作品、交流改进
- 为什么这样做：看最远处时两镜间距约等于两焦距之和，看较近物体时要稍拉长，所以镜筒做成两段便于调节。
- 结论：两块凸透镜按焦距搭配并调好间距，就能做成可以看清远处物体的简易望远镜。
- 注意 / 常见做错：课本为「跨学科实践」项目，没有实验框，暂归为实验；放大倍率不宜过大，否则成像质量差；两段镜筒之间的缝隙要尽量小
- 课本提到的生活例子：伽利略用自制望远镜观察天体、哈勃空间望远镜、郭守敬望远镜、中国天眼

### 第六章 质量与密度

**实验 · 用托盘天平测量物体的质量**（第1节 质量，第 142 页，图6.1-4） — 网站 08
- 器材：托盘天平一台（配砝码盒和镊子）、橡皮、铅笔
- 摆法：天平放在水平桌面上，被测物体放左盘，砝码放右盘。
- 步骤：认识天平各部分：横梁、指针、分度盘、标尺、游码、平衡螺母、砝码 → 把天平放在水平桌面上 → 游码拨到标尺左端零刻度线，调平衡螺母使指针对准分度盘中线 → 物体放左盘，用镊子往右盘加减砝码并移动游码，直到横梁再次水平平衡 → 读数：砝码总质量加上游码左端对应的刻度值 → 称出橡皮、铅笔的质量 → 想一想：小瓶里的水或食盐这类粉末该怎么称
- 为什么这样做：称量前的几条要求（不超称量、用镊子夹砝码、潮湿物和化学药品不直接放盘里）都是为了不损坏天平。
- 结论：按放平、调平衡、左物右码、读数的顺序，就能用天平称出物体的质量。
- 注意 / 常见做错：被测物体质量超过天平的称量；用手直接拿砝码，或把砝码弄湿、弄脏；把潮湿物体、化学药品直接放在托盘上
- 课本提到的生活例子：市场上的台秤、案秤、电子秤、高精度电子天平

**实验 · 探究物质的质量与体积的关系**（第2节 密度，第 144 页，图6.2-2）
- 器材：大小不同、外形规则的铝块若干（其他组可用铁块或木块）、天平一台、刻度尺一把、坐标纸
- 步骤：根据生活经验先提出猜想 → 用天平称出每块铝块的质量 → 想办法得出每块铝块的体积（外形规则，可量尺寸计算） → 把数据填入表格 → 以体积V为横轴、质量m为纵轴描点并连线 → 看各点是否大致在一条直线上得出结论，再与铁块、木块组的结果比较
- 为什么这样做：要看质量和体积的关系，就要选同一种物质、大小不同的物体来测。
- 记录表：被测物体 | m/g | V/cm³
- 结论：同种物质的质量与体积成正比，二者之比是定值；不同物质这个比值一般不同，这个比值叫密度，ρ=m/V。
- 注意 / 常见做错：用刻度尺量体积是按「外形规则」推断的做法

**实验 · 测量盐水的密度**（第3节 测量液体和固体的密度，第 149 页，图6.3-2） — 网站 09
- 器材：天平一台、量筒一个、杯子一个、盐、水
- 步骤：先看清量筒的标度单位、最大测量值和分度值 → 用盐和水自己配一杯盐水 → 用天平称出杯和盐水的总质量m1 → 把杯中一部分盐水倒进量筒，读出体积V（视线与液面相平） → 称出杯和剩下盐水的质量m2 → 量筒中盐水质量m=m1-m2，再用ρ=m/V算出密度
- 记录表：杯和盐水的质量m1/g | 杯和剩余盐水的质量m2/g | 量筒中盐水的质量m（=m1-m2）/g | 量筒中盐水的体积V/cm³ | 盐水的密度ρ/（g·cm⁻³）
- 结论：用天平测质量、量筒测体积，由ρ=m/V就能求出盐水的密度。
- 注意 / 常见做错：量筒读数时视线要与液面相平；溶入的盐多少不同，盐水密度就不同，所以各人测得的结果会不一样
- 课本提到的生活例子：用盐水选种：空粒、瘪粒浮在水面被清除

**实验 · 测量小石块的密度**（第3节 测量液体和固体的密度，第 150 页，图6.3-3） — 网站 09
- 器材：天平一台、量筒一个、水、不吸水的小石块一块、细线一根
- 步骤：用天平称出小石块的质量，记入自己设计的表格 → 量筒里倒入适量水，读出体积V1 → 用细线拴住小石块放进量筒，读出水和石块的总体积V2 → 石块体积V=V2-V1 → 用ρ=m/V求出小石块的密度
- 结论：形状不规则的固体可用量筒排水法测体积，再结合质量求出密度。
- 注意 / 常见做错：石块要选不吸水的；表格需学生自己设计；细线拴石块按插图推断

**想想做做 · 在门上不同位置推门**（第1节 力，第 4 页，图7.1-5）

- 结论：两车同时朝相反方向运动，推墙的人向后退：甲给乙施力的同时，乙也给甲一个反方向的力，力的作用是相互的。

- 步骤：看清测力计的测量范围，弄清一个小格代表多少牛 → 检查指针是否对准零刻度线，没对准就先调零 → 用手拉挂钩，让指针分别停在1 N、3 N、5 N处，体会这几个力有多大 → 把文具袋挂在挂钩上，读出示数，记为拉力F1 → 用测力计沿水平方向拉着文具袋在桌面上移动，读出示数，记为拉力F2 → 归纳使用测力计要注意的操作要点
- 为什么这样做：课本先讲：所加的力不能超过最大测量值，否则会损坏测力计，所以第一步先看量程。

- 注意 / 常见做错：所测的力不能超过量程；使用前检查并调零；弹簧受力不能超出弹性限度，超了就恢复不了原状；练习题提示：由测竖直方向改为测水平方向的力时要重新考虑调零

**演示 · 阻力对物体运动的影响**（第1节 牛顿第一定律，第 19 页，图8.1-2）
- 器材：斜面1个；水平长木板1块（斜面底端接在木板上，板边有刻度）；小车1辆；棉布1块

**实验 · 探究二力平衡的条件**（第2节 二力平衡，第 24 页，图8.2-3）
- 器材：小车1辆；光滑的水平桌面；桌子左右两端各装1个定滑轮；细绳2根；托盘2个；钩码若干
- 摆法：小车放在桌面中间，两端各拴一根细绳，绳子分别跨过桌边的滑轮，下端各挂一个托盘，托盘里放钩码。

- 为什么这样做：实验思路是：先设法让物体在两个力作用下平衡，再在平衡时测量这两个力，看它们之间有什么关系。
- 记录表：小车在水平方向所受二力的情况：大小 | 小车在水平方向所受二力的情况：方向 | 小车在水平方向所受二力的情况：是否在同一直线上 | 小车的运动状态是否改变
- 结论：作用在同一物体上的两个力，若大小相等、方向相反且作用在同一条直线上，二力就平衡。
- 注意 / 常见做错：桌面要光滑，尽量减小小车与桌面的摩擦；扭转小车是为了让两个拉力不在同一直线上；表格「大小」一栏课本已预填：不相等、相等、相等……；平衡状态指静止或匀速直线运动状态

**演示 · 研究同一直线上二力的合成**（第4节 同一直线上二力的合成，第 34 页，图8.4-2）
- 器材：橡皮筋1根（左端固定在竖直板上）；小圆环1个（连在橡皮筋右端）；细绳若干；弹簧测力计2只（各由一只手拿着）
- 摆法：橡皮筋水平放置，左端固定、右端连小圆环；两只测力计各用一根细绳拴在小圆环上，水平拉动；最后只用一只测力计拴在环上拉。
- 步骤：两只测力计都向右沿水平方向拉，把小圆环拉到O点，标出位置，记下示数F1、F2 → 只用一只测力计把小圆环拉到同一个O点，记下示数F合 → 改变F1、F2大小多做几次，比较F合与F1、F2的大小和方向 → 两只测力计沿相反方向水平拉橡皮筋，标出小圆环位置O′，记下F1′、F2′ → 再只用一只测力计把小圆环拉到O′点，记下F合′ → 改变F1′、F2′多做几次，比较大小和方向
- 为什么这样做：每次单独用一只测力计都要把小圆环拉到原来的同一点，使一个力产生的效果和两个力一起产生的效果一样，这时这一个力才算它们的合力。
- 结论：同一直线上两个力方向相同时，合力等于两力之和，方向不变；方向相反时，合力等于两力之差，方向与较大的力相同。

**演示 · 压力和受力面积对海绵形变的影响**（第1节 压强，第 41 页，图9.1-3）

### 第十章 浮力

**演示 · 测量浸没在水中的铝块所受的浮力**（第1节 浮力，第 64 页，图10.1-3）
- 器材：弹簧测力计1只（手提上端圆环）；铝块1块（用细线挂在挂钩下）；盛水的烧杯1个
- 摆法：同一只测力计始终用手提着：甲铝块在空气中；乙铝块完全浸没在烧杯水中；丙铝块浸没得更深一些，都不碰杯底和杯壁。
- 步骤：铝块挂在测力计下，静止时读数，这就是铝块的重力G → 把铝块浸没在水中，静止时读数F拉，看示数变化了多少 → 改变铝块浸没的深度，再读数，看示数有没有变
- 结论：铝块浸没后测力计示数变小，说明它受到浮力，F浮 = G − F拉（称重法）；浸没后再加深，示数不变，浮力与浸没深度无关。
- 注意 / 常见做错：浸没指物体全部处在液面以下；铝块受重力、拉力、浮力三个力平衡，可由此证明F浮 = G − F拉；浮力产生的原因：物体上下表面所受液体压力不同
- 课本提到的生活例子：游船、鸭子、冰山浮在水面、沉在水底的石块也受浮力

**实验 · 探究浮力的大小与哪些因素有关**（第1节 浮力，第 66 页，图10.1-5） — 网站 13
- 器材：弹簧测力计1只（手提）；圆柱形金属块1个（侧面有刻度，挂在挂钩下）；烧杯；水和其他密度不同的液体（如盐水）

**实验 · 探究浮力的大小与排开液体所受重力的关系**（第2节 阿基米德原理，第 69 页，图10.2-2）
- 器材：弹簧测力计1只（全程用手提着，同一只依次称量）；溢水杯1个（侧面有出水口，水装到出水口处）；小桶1个；物体1个（用细线挂）；水
- 摆法：小桶放在溢水杯出水口的正下方接水；物体挂在手提的测力计下慢慢浸入溢水杯。
- 步骤：甲：用测力计称出空小桶的重力G桶 → 乙：用测力计挂物体，在空气中静止时读出物体重力G物 → 丙：把物体浸入溢水杯的水中，静止时读出测力计示数F拉，排出的水流进小桶 → 丁：用测力计称出装水小桶的总重力G总 → 计算F浮 = G物 − F拉，G排 = G总 − G桶，比较二者；换物体或多做几次
- 为什么这样做：课本在实验思路中提出：为减小误差要考虑操作顺序。按图先称干的空桶、再称干的物体，最后才让物体入水、称桶和水，避免桶和物体沾水后再称带来误差。
- 记录表：次数 | 小桶所受的重力G桶/N | 物体所受的重力G物/N | 物体在水中时弹簧测力计的示数F拉/N | 小桶和排开水所受的总重力G总/N | 浮力F浮/N | 排开的水所受的重力G排/N
- 结论：物体浸在液体里所受浮力，等于被它排开的那部分液体的重力，即阿基米德原理 F浮 = G排；在气体中同样成立。
- 注意 / 常见做错：图乙中溢水杯里的水与出水口齐平，水不满会使收集到的排开水偏少；全程只用一只测力计，四次称量都是手提；顺序的理由课本只以问题形式提出，上面是按图示顺序归纳
- 课本提到的生活例子：阿基米德鉴定王冠，跨进浴缸时水溢出

**想想做做 · 制作微型密度计**（第4节 跨学科实践：制作微型密度计，第 77 页，图10.4-5）
- 器材：标度杆：直径约3 mm的棉签实心塑料杆（或细塑料管、细圆珠笔芯）；浮子：泡沫塑料小球（直径约1.2 cm）（或两头封口的粗塑料管）；配重：铜丝（或插入的粗铁丝）；水；标准消毒酒精；4 mm宽彩色胶布
- 摆法：泡沫球套在塑料杆中部做浮子，杆下端缠铜丝做配重，配重在最下面，整支长约8 cm，竖直漂在小瓶液体里。
- 步骤：最简单的做法：吸管下端用蜡封住并缠铜丝，让它竖直浮在水中 → 估算：排开1～2 mL酒精不会溢出，所以密度计质量约1 g → 估算标度杆：合格酒精密度0.86～0.88×10³ kg/m³，两刻度间至少4 mm，算出杆的直径约3 mm → 组装标度杆、浮子、配重 → 放进水里调铜丝长度，使浮子浸没、水面上露出一段杆 → 放进标准消毒酒精，静止后在液面处做记号，以记号为中心贴4 mm宽彩色胶布 → 测老师准备的几瓶酒精，判断是否合格并分析误差
- 为什么这样做：漂浮时浮力等于重力，质量决定排开酒精的体积，所以先定质量；标度杆越细，密度变化时液面位置变化越明显，所以再定直径。
- 结论：密度计漂浮时浮力等于自身重力，液体密度不同，浸入的深度不同，据此读出密度；胶布范围内的酒精密度合格。
- 注意 / 常见做错：这是跨学科实践项目，不是课本中的实验框；配重必须放在最下面，密度计才能竖直漂浮；标度杆太粗会导致液面位置变化太小、难以分辨
- 课本提到的生活例子：消毒酒精密度约0.87×10³ kg/m³，可用密度计初步判断是否合格、普通玻璃密度计用于酿酒、石油、化工、选种

- 结论：质量相同时，速度越大动能越大；速度相同时，质量越大动能越大。
- 注意 / 常见做错：用木块被撞出的远近来显示钢球动能大小：越远表示做功越多、动能越大（转换法）；每次都在同样的水平面上撞木块

**实验 · 探究杠杆的平衡条件**（第1节 杠杆，第 105 页，图12.1-3） — 网站 14
- 器材：带刻度的杠杆1根（中点O支在铁架台上，两端有平衡螺母）；钩码若干（挂在杠杆两侧）
- 摆法：杠杆中点支在支架上，先调平衡螺母使杠杆水平静止；右侧挂的钩码产生动力F1，左侧挂的钩码产生阻力F2，力臂从杠杆上的刻度直接读出。
- 步骤：挂钩码前先拧两端的平衡螺母，让杠杆水平静止 → 左右两边挂上个数不同的钩码，左右挪动钩码，直到杠杆又在水平位置静止 → 记下F1、F2，读出动力臂l1和阻力臂l2，填表 → 保持F2和l2不变，改变F1并调节l1，再做几次 → 保持F1和l1不变，改变F2并调节l2，再做几次 → 分析数据，找出四个量的关系
- 为什么这样做：先固定左侧的阻力和阻力臂、只改右侧的动力和动力臂，再反过来固定右侧、改左侧，合起来分析就能找出这四个量的关系。
- 记录表：次数 | 动力F1/N | 动力臂l1/m | 阻力F2/N | 阻力臂l2/m
- 结论：杠杆平衡时满足 F1l1 = F2l2（动力与动力臂之积等于阻力与阻力臂之积），也叫杠杆原理（由阿基米德发现）。
- 注意 / 常见做错：杠杆每侧受到的拉力就等于那一侧钩码的重力；平衡螺母只在挂钩码之前调节；挂上钩码后靠移动钩码位置来平衡；让杠杆在水平位置平衡，力臂可直接在杠杆上读出

- 结论：两个铅柱没有被重物拉开，主要是因为分子之间存在引力。
- 注意 / 常见做错：接触面必须平整干净并用力压紧；复习题指出：根据接触面积和所挂重物可以算出，大气压不是铅柱吊起重物的主要原因
- 课本提到的生活例子：固体和液体能保持一定的体积、固体和液体很难被压缩，说明分子间还有斥力

**演示 · 做功改变空气的内能**（第3节 内能，第 16 页，图13.3-5）
- 器材：带活塞的厚玻璃筒1个，脱脂棉一小团；烧瓶1个，少量水，瓶塞，打气筒（带导管）
- 摆法：甲：脱脂棉放在厚玻璃筒底部，活塞插在筒口。乙：烧瓶内装少量水，塞紧瓶塞，打气筒的管子通入瓶内。
- 步骤：甲：在厚玻璃筒里放一小团脱脂棉，把活塞迅速压下去，观察现象 → 乙：在烧瓶内装少量水，塞紧瓶塞 → 乙：用打气筒向瓶内打气，瓶塞跳起时观察瓶内的变化 → 思考两个实验分别通过什么方式改变了空气的内能
- 结论：压缩空气做功，空气内能增加、温度升高到脱脂棉燃点；瓶内气体推开瓶塞对外做功，内能减少、温度降低，水蒸气液化成白雾。做功可以改变物体的内能。
- 注意 / 常见做错：甲实验活塞必须迅速压下；乙实验中瓶内本来就有看不见的水蒸气，瓶塞跳起时出现的白雾是小水滴，不是水蒸气
- 课本提到的生活例子：冬天搓手取暖（图13.3-4甲）、从滑梯上滑下臀部发热（图13.3-4乙）、搅拌能让水温升高，捶打能使铁块变热、装开水的暖水瓶有时瓶塞会弹起（本节问题引入）

**演示 · 电荷间的相互作用**（第1节 两种电荷，第 40 页，图15.1-2）
- 器材：玻璃棒2根，丝绸，橡胶棒1根，毛皮，可悬挂的支架（细线吊起其中一根玻璃棒）
- 摆法：一根用丝绸摩擦过的玻璃棒用细线水平吊起，可以自由转动。
- 步骤：用丝绸分别摩擦两根玻璃棒，把其中一根吊起来 → 手拿另一根玻璃棒去靠近被吊起的玻璃棒，观察现象 → 手拿用毛皮摩擦过的橡胶棒去靠近被吊起的玻璃棒，观察现象
- 结论：两根丝绸摩擦过的玻璃棒互相排斥，玻璃棒与毛皮摩擦过的橡胶棒互相吸引：同种电荷相互排斥，异种电荷相互吸引。

- 结论：通电导线在磁场中受到力；力的方向跟电流方向和磁场方向都有关，只改变其中一个，受力方向就反过来。
- 注意 / 常见做错：每次只改变一个因素；思考：电流和磁场同时反向，受力方向会怎样（不变）
- 课本提到的生活例子：电力机车、电梯、电风扇、冰箱、洗衣机、工业机器人（图20.4-1）、电动玩具都靠电动机

**演示 · 通电线圈在磁场中转动**（第4节 电动机，第 162 页，图20.4-3）
- 器材：磁体1套（S、N两极相对）、可转动的矩形线圈1个、电源1个、开关1个、导线
- 摆法：线圈放在两个磁极之间的磁场里，能绕轴转动；线圈经开关接电源。
- 步骤：让线圈停在图乙位置（平衡位置），闭合开关：线圈不动 → 让线圈停在图甲位置，闭合开关：线圈顺时针转，因惯性冲过平衡位置，但转不过去又回到平衡位置 → 让线圈停在图丙位置（冲过平衡位置后到达处），闭合开关：线圈逆时针转
- 为什么这样做：先说明平衡位置上线圈上下两边受力等大反向，再用甲、丙两个位置解释线圈为什么会被拉回来、不能一直转。
- 结论：通电线圈只能在平衡位置附近摆动，不能连续转；若在越过平衡位置后改变线圈中电流方向，就能持续转动，这就是换向器的作用。
- 注意 / 常见做错：平衡位置：线圈上、下两边受力大小相等、方向相反

**想想做做 · 制作简易直流电动机（跨学科实践中的制作方法）**（第5节 跨学科实践：制作简易直流电动机，第 166 页，图20.5-2）
- 器材：粗漆包线1段、强磁体1块、电池1节（可带电池盒）、硬金属丝2段（做支架）、硬纸板、小刀
- 摆法：两个金属丝支架固定在硬纸板或电池盒上，分别连电池两极；线圈两端引线架在支架上；线圈正下方放强磁体。
- 步骤：用漆包线绕一个约3 cm×2 cm的矩形线圈作转子，两端各留约2 cm作转轴 → 用硬金属丝做两个支架并固定，分别接电池正、负极 → 用小刀刮引线的漆皮：一端全部刮掉，另一端只刮半圈 → 把线圈放到支架上，下方放强磁体作定子 → 通电后用手轻轻推一下线圈，让它转起来 → 调试，让电动机转得更好
- 为什么这样做：一端只刮半圈，线圈转到下半周时断电，反向的力没有了，靠惯性转过去，起到代替换向器的作用。
- 结论：线圈上半周通电、下半周断电，靠惯性就能连续转动。
- 注意 / 常见做错：漆皮不刮就不导电；通电后要轻推一下才能启动；转轴摩擦大小会影响转动
- 课本提到的生活例子：玩具电动车用直流电动机驱动

**实验 · 探究导体在磁场中运动时产生感应电流的条件**（第6节 磁生电，第 167 页，图20.6-2） — 网站 22
- 器材：蹄形磁体1个（另备不同强度的永磁体）、导线1根（ab）、电流表（灵敏电流计）1只、连接导线
- 摆法：蹄形磁体平放，两极上下相对；导线ab横穿两极之间的磁场，两端连到电流表上，组成闭合电路。
- 步骤：让导线在磁场中静止，看电流表指针是否偏转 → 换用强度不同的永磁体，导线仍静止，再看 → 让导线在磁场中朝不同方向运动（上下、左右、前后），看是否有电流 → 分析各次现象，总结产生电流的条件
- 为什么这样做：先试导线静止，再试导线运动，对比找出产生电流的条件。
- 结论：闭合回路中的一段导体切割磁感线运动时，导体里就会产生电流，叫电磁感应，产生的电流叫感应电流；导线左右运动方向相反时，电流方向也相反。
- 注意 / 常见做错：电路必须闭合，要接入电流表才能看出有没有电流；可以把磁感线想成一根根线、导线想成刀，“切”到线才有电流
- 课本提到的生活例子：法拉第1831年发现磁生电、发电机就是根据这个原理制成的

**演示 · 手摇发电机发电**（第6节 磁生电，第 169 页，图20.6-5）
- 器材：手摇发电机1台、小灯泡1只、发光二极管2只、导线
